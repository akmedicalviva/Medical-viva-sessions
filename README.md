# 🎓 AI Medical Viva Examiner - SECURE & FREE

An AI-powered platform for medical students to practice viva examinations with voice recognition.

## ✨ Key Features

✅ 🎙️ **Voice Recognition** - Unlimited voice recording (browser-based)
✅ 🗣️ **Natural Speech** - Professor speaks questions (browser TTS)
✅ 📚 **Multiple Books** - Practice from various sources
✅ ⏱️ **Timed Sessions** - Realistic exam conditions
✅ 📊 **Analytics** - Track performance trends
✅ 🔒 **Secure** - NO API KEYS EXPOSED
✅ 💾 **Offline** - Works without internet
✅ 📱 **Mobile-First** - Perfect on phones

## 🔐 Security Features

- ✅ No API keys in frontend code
- ✅ Browser-based speech (Chrome engine)
- ✅ Browser-based text-to-speech
- ✅ Password hashing
- ✅ Login brute-force protection (15 min lockout after 5 failed attempts)
- ✅ Session isolation (students see only their data)
- ✅ No sensitive data exposure

## 🆘 Troubleshooting

**Q: Microphone not working?**
- Use Chrome browser
- Allow microphone permission
- Or type answers manually

**Q: Voice not working?**
- Check browser supports Web Speech API
- Try different browser
- Manual typing always available

**Q: Data disappearing?**
- Browser data cleared?
- Use different browser
- Download results regularly
